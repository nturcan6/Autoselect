AUTOSELECT - Netlify + Supabase

Archivos:
- index.html: web pública para clientes
- admin.html: panel de gestión
- autoselect-futuristic-hero-1/2/3.png: imágenes de portada
- supabase-setup.sql: SQL usado para crear la tabla cars

Subida a Netlify:
1. Sube todo el contenido de esta carpeta a Netlify.
2. Tu web pública abrirá index.html.
3. Para administrar entra en /admin.html.

Importante:
La configuración actual permite escritura pública en Supabase porque es una versión simple en HTML estático.
Cuando confirmes que funciona, conviene proteger el panel con login real y cambiar las políticas RLS.
